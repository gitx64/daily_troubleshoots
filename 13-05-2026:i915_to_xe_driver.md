## i915 is for older graphics of integrated intel. So for newer intel iris xe graphics it is good way to change the driver to xe driver instead of i915:

-> Step 1: Find your exact GPU PCI ID

```bash
lspci -nn -s 00:02.0
```
It will show something like: 8086:46a6
Note down the last 4 characters (e.g. 46a6).

- Step 2: Force the xe driver (Recommended method)

Create a config file for GRUB:

```bash
sudo vim /etc/default/grub
```
Find the line that starts with GRUB_CMDLINE_LINUX_DEFAULT= and add this at the end (inside the quotes):

GRUB_CMDLINE_LINUX_DEFAULT="quiet splash i915.force_probe=!46a6 xe.force_probe=46a6"

replace 46a6 with the actual 4 character you previously copied.

then update and reboot:

```bash
sudo update-grub
sudo reboot
```

- Step 3: Verify after reboot

```bash
lspci -k -s 00:02.0
```
You should see Kernel driver in use: xe

also check if in opengl renderer mesa and the actual graphics driver is showing: 

```bash
glxinfo | grep "OpenGL renderer"
```

### How to Go Back to i915 (Important!)

If you face issues (black screen, instability, etc.), boot into recovery or use the previous kernel from GRUB menu, then remove the parameters:

```bash
sudo nano /etc/default/grub
```
Delete the i915.force_probe and xe.force_probe part, then:

```bash
sudo update-grub
sudo reboot
```
