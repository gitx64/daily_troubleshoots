In /tmp directory any user can create directories of their choice but no one can see them except root privillegers not even the user who created the directory if they forgot the name. And /tmp directory also removes all the things stored in it trashed or remove them after a reboot, thats why its called tmp (temporary).

OR

You can you this command to generate a temporary directory in any location until next reboot:

```bash
mktemp -d
```
